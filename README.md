## ✨ 项目简介

**马喽助手** 是一款基于 Auto.js Pro 开发的 Android 端钉钉自动考勤打卡自动化工具。通过监听本地通知触发打卡流程，支持上班打卡、下班打卡、加班打卡等多种场景，并通过 Socket.io 与服务端进行实时通信，支持配置同步、状态上报以及多种推送渠道（企业微信 / Server酱）。

项目采用模块化架构设计，代码逻辑清晰，易于维护和扩展。适用于需要自动化考勤管理的个人或团队场景。

## 🎯 核心功能

| 功能 | 描述 |
| :--- | :--- |
| 🔔 **通知监听触发** | 通过监听本地通知（钉钉/企业微信/马喽助手）自动触发打卡流程 |
| ☀️ **上班打卡** | 上午 10 点前自动进入上班打卡流程 |
| 🌙 **下班打卡** | 上午 10 点后自动进入下班打卡流程 |
| ⏱️ **加班打卡** | 支持加班场景的特殊打卡流程 |
| 🌙 **睡觉模式** | 通过通知触发锁屏流程 |
| 🖼️ **图像识别** | 基于 OpenCV 的找图找色识别考勤界面状态（浅色/深色模式适配） |
| 📱 **屏幕自动控制** | 自动亮屏、解锁、锁屏、亮度调节 |
| 🔌 **Socket.io 通信** | 与服务端实时连接，状态上报、消息接收、配置同步 |
| 📢 **多渠道推送** | 支持企业微信 / Server酱 推送考勤结果及状态通知 |
| 👤 **用户认证** | 账号密码登录 + Token 持久化验证 |
| 💾 **双配置存储** | 本地存储 + 服务端双重保存配置信息 |
| 🪟 **悬浮窗保活** | 悬浮窗 + 音乐播放提升应用存活率 |
| 🔐 **权限管理** | 无障碍、截图、通知、修改系统、使用统计等权限统一管理 |
| ⏳ **随机等待** | 支持 1-5 分钟随机延迟启动，模拟真实用户行为 |

## 🚀 快速开始

### 环境要求

- **Android 系统**: 8.0 及以上
- **打包环境**: Auto.js Pro 8.x
- **架构支持**: arm64-v8a
- **钉钉版本**: 建议使用最新版官方钉钉 APP

### 安装步骤

1. **克隆项目**: 将项目下载到本地
2. **打开项目**: 使用 Auto.js Pro 9 打开项目根目录
3. **配置服务端 IP**: 首次启动后，点击登录界面的「修改服务器 IP」按钮，填入服务端地址
4. **登录账号**: 使用管理员分配的用户名和密码登录
5. **填写配置**: 在主界面填写推送相关配置（UID/Key/CorpId）
6. **授权权限**: 在侧边栏开启所有必需权限
7. **选择推送方式**: 选择企业微信或 Server 酱作为推送渠道
8. **启动监听**: 点击「开始监听」按钮，启动通知监听

### 使用流程

1. 服务端或系统向目标手机发送带有 `{用户名}打卡` 关键词的通知
2. 马喽助手监听到通知后自动唤醒屏幕并解锁
3. 自动启动钉钉 APP 并进入考勤界面
4. 根据当前时间判断执行上班 / 下班打卡流程
5. 打卡完成后通过企业微信或 Server 酱推送考勤结果
6. 支持通过发送 `{用户名}查询` 查询上次考勤结果
7. 支持通过发送 `{用户名}加班` 执行加班打卡流程
8. 支持通过发送 `{用户名}睡觉` 执行锁屏流程

## ⚙️ 配置说明

### 服务端配置

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `serverUrl` | `113.14.158.122:7011` | 服务端 Socket.io 地址及端口 |
| `url_scheme` | `dingtalk://...` | 钉钉考勤页面 URL Scheme |

### 运行参数

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `LOWER_BOUND` | `1 min` | 随机等待最小时间 |
| `UPPER_BOUND` | `5 min` | 随机等待最大时间 |
| `SCREEN_BRIGHTNESS` | `20` (0-255) | 执行打卡时的屏幕亮度 |

### 推送配置

在主界面填写以下字段后点击「写入配置」：

- **用户名 (username)**: 打卡使用的用户名标识
- **UID**: 推送渠道的用户标识
- **Key**: 推送渠道的密钥
- **CorpId**: 钉钉企业 CorpId（用于 URL Scheme 跳转考勤页）

## 🤝 贡献指南

欢迎提交 Issue 和 Pull Request 来帮助改进本项目！

**开发环境搭建**：
1. 安装 Auto.js Pro 8.x
2. 安装 Node.js 环境用于依赖管理
3. 执行 `npm install` 安装开发依赖（类型定义、自动补全）

**开发规范**：
- 保持模块化架构，核心功能放在 `rec/cli/` 目录
- 配置项集中管理在 `rec/config/` 目录
- 关键函数需要添加 JSDoc 注释
- 变量命名请遵循现有代码风格（如 `Ml_` 前缀表示马喽助手模块）
